# カコモと学ぶ 決算チャレンジ 商工費編

加古川市 令和7年度一般会計決算「商工費」(約19.9億円)を、クイズと予算判断
シミュレーションで学べる単一HTMLファイルのPWAです。

## この款で見つかった「気になる点」

- **出資金5億円**: 商工業振興一般事業の中に、第三セクター「加古川再開発
  ビル株式会社」への増資(株式16,666株取得)として約5億円が計上。
  商工費全体の約4分の1にあたる金額で、増資の必要性の詳細は決算資料からは
  分からない
- **ふるさと納税推進事業のコスト構造**: 寄附金額(約3.94億円、目標5億円
  未達・前年度比▲12.9%)に対し、返礼品費・郵送料・手数料・システム利用料
  等の合計が約1.84億円(寄附額の約47%)。さらに郵便料(約1,596万円)と
  受付手数料(約4,272万円)は支払先明細に一切記載がなく、誰に払ったか
  個別には追えない
- **翌年度繰越額が款全体の47%**: 商工費決算総額(約19.9億円)に対し、
  翌年度繰越額は約9.35億円。9事業一覧側で確認できる繰越は旧公設地方
  卸売市場整理事業の約3.47億円のみで、残り約5.88億円の使いみちは
  9事業の公開資料からは追いきれなかった(不正を示すものではなく、
  現状の公開資料の粒度では検証しきれないという趣旨で扱う)
- 一般社団法人加古川観光協会が4事業にまたがり合計約7,159万円、
  加古川商工会議所が2事業にまたがり合計約6,098万円を受託・受給

## 構成

1. **入口クイズ層**(19問、2択): 基礎知識5問(出資金・ふるさと納税・
   繰越の気になる点を含む)+予算vs決算9問+特別トリビア5問
2. **本編シミュレーション層**: 9事業。全て裁量事業(法定給付なし)
3. **答え合わせ層**: 未実装(他の款と同様)
